## Features / 特長
- 🌐 日本語 / English
- 🌙 Matrix Green dark theme ・ ☀️ Normal theme
- 🏆 Teams, group stages, full leagues and brackets — just type the names
  チーム分け・予選リーグ・リーグ戦・トーナメント表まで、名前を入れるだけ
- 🎓 Strategy trainers and built-in guides (Casino 21, Video Poker, Baccarat, Sic Bo, Shut the Box)
- ⌨️ Keyboard play supported
- 📦 Each game is a single HTML file

## Privacy / プライバシー
- No ads, no account, no cookies.
- Settings and records are stored only in your browser (localStorage).
  設定や記録は、お使いのブラウザの中だけに保存されます。
- Only an anonymous page-view count via [GoatCounter](https://www.goatcounter.com/).
- Chips and medals are for fun only — no real money.
  ゲーム内のチップやメダルは遊び用で、本物のお金とは関係ありません。
